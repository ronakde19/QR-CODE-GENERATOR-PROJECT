## Requirements 📋

- Python 3.x

## Setup ⚙️

1. **Clone this repository**
2. **Create a virtual environment** (optional but recommended):
   ```bash
   python -m venv venv
   ```
3. **Install the required libraries**:
   ```bash
   pip install qrcode[pil]
   ```

## How to Run ▶️

To run the QR Code generator, execute the following command in your terminal:
```bash
python qrcodegenerator.py
```

When prompted, enter your text or URL and specify a filename. The QR code image will be saved in the same folder.
